# 给豆包的话 · 生成剩下 6 个英雄的卡面

> 用途：直接复制下面「一」整段粘给豆包即可。已经有 45 个英雄的卡面（风格统一：平涂 + 粗黑描边 + 透明底 + 全身站立居中 + 无文字），
> 只差这 6 个：**负墟、坠炮手、宿魂、共鸣者、装甲堡垒、荆棘树人**。
> 生成后按「三」的命名丢进 `assets\英雄卡面\`，我来抠透明底 + 重导入。

---

## 一、可直接粘贴的那段话

```
我在做一款酒馆奇幻题材的六边形战棋游戏，英雄卡面已经画了 45 张，画风统一：
平涂色块 + 粗黑描边、没有渐变和光影、全身正面站立、居中、透明背景、画面里不出现任何文字，
身体占满画面高度的 85~90%。请严格按这个画风，帮我再画下面 6 个英雄，一次画一张。

【每张都要带的风格描述 —— 原样放在最前面】
flat cartoon game character, thick black outline, solid flat colors, no shading,
simple chunky shapes, full body, front view, centered, transparent background,
one character only

【每张都要排除的东西】
shading, gradients, highlights, soft shadow, ground shadow, texture, patterns,
scenery, background objects, extra props, clutter, glow, particles, dust, smoke,
frame, border, text, watermark, logo, multiple characters, busy, intricate,
detailed, realistic, 3d render, photorealistic

【输出规格】
1:1 正方形；1024×1024；透明背景（出不了透明底就出纯白底）；主体居中、脚到头撑满；
不要画边框、不要画卡框、不要写任何文字（包括英雄名）。

【要画的 6 个英雄】
1. 负墟（魔族·抗揍的肉盾）：深渊黑重甲巨汉，甲面上有发光裂纹，身上挂着断掉的锁链，站姿沉稳不可撼动。
   black armored juggernaut, cracked plates
2. 坠炮手（人族·远程炮兵）：迫击炮手，戴钢盔，扛一门超大的炮，身上挂着炮弹带。
   gunner, helmet, one big cannon
3. 宿魂（魔族·幽灵刺客）：兜帽刺客，上半身半透明像幽灵，双手各一把匕首，脚下有淡淡烟雾。
   ghost assassin, hood, twin daggers
4. 共鸣者（精灵·法师）：精灵法师，身边漂浮着音叉和小钟，胸口有扩散的音波光环，头发被声波扬起。
   elf mage, floating tuning forks
5. 装甲堡垒（机械·行走堡垒）：会走路的城堡机甲，肩甲像城垛，装甲厚重，底座稳如磐石。
   walking fortress robot, castle armor
6. 荆棘树人（精灵·树精）：树皮身体的人形树精，手臂缠满带刺藤蔓，站稳不动。
   treant, bark body, thorn vines

画的时候请和我画风保持一致：色块平涂、描边粗、细节少、不要背景道具。
```

## 二、单张重画模板（某一张不满意时用）

```
沿用刚才那套画风（平涂 + 粗黑描边 + 透明底 + 全身居中 + 不要文字），只改主体描述，重新画这一张：

flat cartoon game character, thick black outline, solid flat colors, no shading,
simple chunky shapes, full body, front view, centered, transparent background,
one character only
<把这一行换成本次要画的那句，例如：gunner, helmet, one big cannon>

排除：shading, gradients, highlights, shadows, texture, scenery, background objects,
clutter, glow, frame, border, text, watermark, multiple characters, realistic, 3d render
```

**三个能明显提高一致性的做法**（跟豆包说清楚就行）：
1. **先发参考图**：把已经画好的 2~3 张（比如 `伐木工.png`、`塔盾.png`、`红帽.png`）发给它，说「照着这几张的画风和构图比例来」—— 这比堆形容词有效得多。
2. **一次只画一张**，别让它一口气画 6 张（风格会飘、细节会越画越多）。
3. **风格串一个字都别改**，只换主体那一行；觉得不像就只加主体里的词（最多 4 个词）。

## 三、画完之后（交给我）

1. 存成 **`assets\英雄卡面\<中文名>.png`**，中文名必须和游戏里的一致：
   `负墟.png`、`坠炮手.png`、`宿魂.png`、`共鸣者.png`、`装甲堡垒.png`、`荆棘树人.png`
   （差一个字游戏就找不到 —— 之前"医疗兵/独角龟/小骷髅"就是名字对不上，我改过。）
2. 跟我说一声，我会跑：
   - `tools\抠英雄卡面.ps1`：把纯色底抠成透明底 `<中文名>_人物.png`（人物周围的星星/礼物等装饰会保留，只丢底色噪点）
   - `godot --headless --path . --import`：重导入
   ⇒ 游戏里那张卡和棋盘上的棋子**自动**换成新人物（有图的英雄不画名字），不用改代码。
