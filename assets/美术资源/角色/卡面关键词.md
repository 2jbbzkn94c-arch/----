## 一、通用模板（每个英雄都套这个）

**风格前缀（S，原样放最前面，就这么短）**

```
flat cartoon game character, thick black outline, solid flat colors, no shading,
simple chunky shapes, full body, front view, centered, transparent background,
one character only
```

**负面词（N，固定不变 —— 复杂度就是靠这段压住的）**

```
shading, gradients, highlights, soft shadow, ground shadow, texture, patterns,
scenery, background objects, extra props, clutter, glow, particles, dust, smoke,
frame, border, text, watermark, logo, multiple characters, busy, intricate,
detailed, realistic, 3d render, photorealistic
```

**参数**

- 比例 **1:1**；出图 1024×1024 就够（**别出 2048**，细节反而更乱）。
- **底 = 透明色**（工具不支持透明就出**纯白底**，见下面 §三 第 3 条的抠图流程）。
- **边框为正六边形，正六边形横线在上边**（平顶）⇒ 主体按这个形状摆：**居中、脚到头撑满**（高度占 85~90%），四角别超出六边形（超出去的部分贴进卡里会被裁掉）。
- **一致性三件套**：同一模型 + 同一风格前缀 S + **固定 seed**（只改主体描述）；同一批英雄一次出完，风格才不飘。每个角色出 3 张挑 1 张。

**种族配色点缀（让 49 张摆在列表里能一眼分族）**

| 种族 | 主色 | 点缀 |
|---|---|---|
| 人族 | 皮革棕 / 旧钢灰 | 暖橙灯影 |
| 精灵 | 苔绿 / 浅金 | 冷白月光 |
| 兽族 | 赭黄 / 土橘 | 深褐斑纹 |
| 魔族 | 暗紫 / 血红 | 幽绿或紫罗兰微光 |
| 机械 | 黄铜 / 铁灰 | 暖黄灯 / 蒸汽白 |

**每行只写 2~4 个词**：`主体 + 最多一个道具 +（可选）一个颜色`。
写多了模型就开始加戏 —— 觉得还不够像，**最多加到 4 个词**；第 5 个词起基本只会添乱。

## 三、还想更省事 / 更简单的三招

1. **喂参考图**（最有效）：把游戏原有的 `assets/美术资源/角色/伐木工.png` 当**风格参考 / img2img 参考图**，权重 **0.4~0.6** —— 复杂度会被直接按在"平涂 + 粗描边"上，比堆词管用得多。
2. **再减档**：某张还是花，就把那行砍到**只剩前两个词**（例如 `lumberjack, plaid shirt`），S / N 不动。
3. **工具出不了透明底**：出**纯白底**、存成 `assets/英雄卡面/<中文名>.png` 丢进来，跟我说一声，我用同一套流程抠成透明底（四周留 2% 全透明边，贴进六边形卡/棋子才不会出现硬切边）。

## 四、图片放哪、怎么命名（决定游戏里哪张卡会用它）

- `assets/英雄卡面/<中文名>_人物.png` = **透明底**人物 ⇒ **选人卡与棋盘棋子用的就是这张**（推荐）。
- `assets/英雄卡面/<中文名>.png` = 带底整图（兜底；卡里会把整张方图塞进六边形 ⇒ 一般别用这个名）。
- 卡里会自动：**等比放大到顶满六边形 + 按六边形裁剪 + 带 mipmap 采样**（不会溢出、不会糊）；有图的英雄**不再画名字**，没出图的照旧显示名字。
