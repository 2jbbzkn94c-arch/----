## 4. 落停引爆：不只是评分，**状态层原来根本没建模**（顺带发现并修掉）

写炸弹场景时发现更严重的一条：模拟只把炸弹格从"落点候选"里剔除，**落停那一下的爆炸与伤害完全没算**。
真实规则（`Battle._bomb_enter_check` 只在路径终点判定 → `_explode_bomb_at`）：
① 炸弹格清除；② 落停者吃 `BOMB_DAMAGE = 5`（`take_damage(5,false,false)`：非攻击伤害 → 坚固不减、
圣盾照挡并消耗、重伤 +1、塔盾照扛）；③ 炸弹人免疫；④ **若这一下把人炸死，`_finish_move` 不会被调用**
（拾取/移动后技能/移动道具清算统统不发生）。

fork 的 `_apply` 已按此补齐（并整段用 `if u.alive:` 包住后半段）。

新场景 `带炸弹·落停引爆`（全 49 英雄）修复前后：
```
修复前：hero_06·带炸弹·落停引爆|DIFF|真实=8/16、bombs 清空 | 模拟=13/16、炸弹还在
        hero_13·带炸弹·落停引爆|DIFF|真实=25/33、bombs 清空 | 模拟=30/33、炸弹还在
        hero_35（炸弹人，免疫）|MATCH  ← 免疫路径本来就对
修复后：hero_06·带炸弹·落停引爆|MATCH|units+hero_06@(2, 5)=8/16|eatk=3|emove=3|已动 ; bombs:["(2, 5)"]→[]
        hero_35·带炸弹·落停引爆|MATCH|… bombs:["(2, 5)"]→["(2, 5)", "(2, 6)"]（免疫 + 布雷）
```
harness 侧为此新增了场景键 `bombs: [格…]`（`_setup` 里预置炸弹），既有场景与判定一律未改。
