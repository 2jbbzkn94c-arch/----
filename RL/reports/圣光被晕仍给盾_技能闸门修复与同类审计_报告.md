## 1. 结论先说

用户报的「圣光被晕，怎么会生成圣盾」是**真 bug**，根因是**延迟发盾的那一帧没有二次判闸门**：

1. 圣光的被动 `on_someone_damaged` 本身确实没判 `unit.skill_allowed()`；
2. 但**当前代码里 Battle 的派发点已经拦了一道**（`src/Battle.gd:3602-3605`：
   `for s in units: if s.alive and s.skill_allowed(): _hero(s).on_someone_damaged(u, amount)`），
   所以"先被晕 → 后挨打"这一路**现版本不会漏**（取证 A / D 组实测：修前修后都不给盾）；
3. 真正漏的是**同一帧内的时序**：圣光在"队友受伤那一刻"还没被晕 → 钩子跑完 → `unit.once_this_turn = true`
   并把 `grant.call_deferred()` 排进下一帧 → **紧接着圣光吃到[眩晕]** → 下一帧 lambda 执行时，
   lambda 里只判了 `m.alive` / `t.alive` / 同阵营，**没判 `m.skill_allowed()`** → 盾照发。
   于是玩家在同一屏里看到「圣光已被晕」+「圣盾生成」。
4. 这不是编出来的时序：**猎颅者（hero_39）的登场技就是"先伤害、后眩晕"**
   （`heroes/hero_39_猎颅者.gd` → `Battle._hurt_lowest_enemy_stun`：先 `take_damage(3)`
   再 `_add_status_msg(best, StatusDB.STUN)`，见 `src/Battle.gd:4168-4179`），
   而按项目自己的"状态施加者"表，它是唯一会施加[眩晕]的英雄
   （`autoload/DataRegistry.gd:310` `"眩晕": ["hero_39"]`；旁证：`heroes/*.gd` 里除 STUN 判定外
   只有 `_hurt_lowest_enemy_stun` 一处会 `add_status(STUN)`）。
   圣光是玩家方单位、登场技打的是"敌方 HP 最低者"——只要圣光是场上血最低的那个，它就会
   在**同一个函数里**先被打了 3 点（此帧未晕）再被晕，正好命中这个 bug。

修法就是**在这两个位置各判一次闸门**（触发判定 + 下一帧的 lambda），与项目别处（反击、塔盾、
坠炮手、共鸣者）对 `skill_allowed()` 的用法完全一致；同时**不改任何其它判据**。

## 3. 验收：四个对照的实测证据

### 3.1 取证场景怎么搭的

`RL/reports/forensics/圣光闸门取证.gd`（`extends Node`，用 `--scene` 跑）：

- `load("res://scenes/Main.tscn").instantiate()` 并把 `GameState.player_placement/enemy_placement`
  预设成 `{圣光} / {敌人}`，让 `Battle._ready()` 走 `_place_units() → _start_match()`，
  棋盘/HUD/信号连接全部走**生产路径**（不是手搓对象）；
- 然后清场，逐组重新 `battle._spawn_unit()` 出「圣光(我方) + 小阴影(我方队友)」，
  `GameState.active_side = SIDE_ENEMY`（敌方回合 → 满足圣光"只在敌方回合"的前提），
  并把 `GameState.match_running = false` 关掉回合倒计时/自动结束/胜负判定这条线，避免取景被打扰；
- 受伤走**真实信号链**：`ally.take_damage(3,...)` → `Unit.damaged` → `Battle._on_unit_damaged`
  → 圣光钩子 → `grant.call_deferred()`；
- 「等帧」用 `await get_tree().process_frame`（idle 帧）——`call_deferred` 的 lambda 正是在 idle
  帧边界执行，所以"等 1 个 idle 帧"就等于"让发盾 lambda 真的跑过一遍"；
- 每组结束后 `_clear_board()` + **等 3 个 idle 帧**，确保上一组残留的 deferred 先跑掉，不串场。

## 5. 用户怎么手动验

1. 开一局，**带上圣光（hero_22）**；用猎颅者（hero_39）当替补，让圣光成为你方**当前 HP 最低**的英雄
   （猎颅者登场技只打"敌方 HP 最低者"，会先打它 3 点、再给它挂[眩晕]）。
   - 圣光是玩家方单位，猎颅者的"敌方"= 你方，所以它会在**敌方回合**（敌方的替补登场）里
     既掉血又被晕，正好复现修复前那条时序。
   - 或者更省事：任何会让你方单位"在同一帧里先受伤、后吃眩晕"的场面都行。
2. 看到圣光牌面出现「晕」字之后，再让**另一名队友**在**敌方回合**里掉血
   （敌方单位打它、或猛毒/烧血等在敌方回合结算的伤害）。
3. **现在应该看到的现象**：
   - 不会再弹出「圣光为 X 施加[圣盾]」，队友身上也不会出现「盾」字；
   - 圣光头上不会再在"晕"的状态下冒出圣盾。
4. 反面对照（确认没改坏）：**不晕不默**的圣光，在敌方回合里队友受伤后，仍然照旧弹
   「圣光为 X 施加[圣盾]」，且**一回合只给一次**（同一回合第二名队友受伤不再给）。
5. 圣光被[沉默]（沉默术士 hero_34 攻击它即可）时，同样**不应**再给盾。
6. **名额退还（第二轮新增）**：让圣光在**敌方回合**、且它自己被[眩晕]（或[沉默]）的状态下让队友挨一次打
   （例如先让沉默术士打圣光、再让敌方单位打队友）——这一次**不会**给盾，而且这次失败**不会**吃掉名额。
