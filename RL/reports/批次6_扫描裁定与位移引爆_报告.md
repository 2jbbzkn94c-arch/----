## 1. 裁定：扫描里的 A 类（移动拾取道具）与 B 类（烛火烧障碍）**都不是模拟缺口**

两类在 4 个种子文件里共 **11 条**记录，我逐条核对了它们紧跟的字段层结论：

```
s11: 判定 DIFF：…实际 道具 (1,3)（被拾取）      → 字段级：diffs=-
s11: 判定 DIFF：…实际 障碍 (2,4) 耐久 3→2      → 字段级：diffs=-
s22: ×4（2 条道具 + 2 条障碍）                → 字段级：diffs=-  ×4
s33: ×2（道具）                               → 字段级：diffs=-  ×2
s44: ×4（2 条道具 + 2 条障碍）                → 字段级：diffs=-  ×4
（C 类 3 条墓碑 = 唯一带真实字段差异的）
```
**11/11 的字段级差异都是空的** —— 也就是说模拟侧的道具格/障碍耐久**与真实逐字段一致**，
只有"可读层"那行 `预测 | 地形/道具：无变化` 少写了。两条独立佐证：

1. 我自己按你的命令复跑（`--selftest 20 --seed 11|22|33|44`，日志 `RL/reports/mysweep_s*.log`）：
   - seed11：同样 2 条 A/B，`字段级：diffs=-`；外加 1 条墓碑（真实字段差异，预期）。
   - seed22 / seed33：检视器**现在自己就把这两类标成 `判定 DIFF（字段层漏报）`**（它的负责人已经定性为自己的显示层缺陷）。
   - seed44：**0 条** DIFF。
2. 检视器的字段层**确实**会比道具与障碍耐久（`_terrain_diffs("道具", sim.buff_cells, …)` /
   `("障碍耐久", sim.obstacles, …)`）：如果模拟盘面还留着道具、或耐久没减，字段层一定会报出来。它没报 → 模拟是对的。

## 2. 本轮真正修掉的缺口：涌电技师的电击/反噬伤害类型（hero_38）

新场景 `带道具·移动捡圣盾` 把一条真缺口顶出来了：
```
修复前：hero_38·带道具·移动捡圣盾|DIFF|真实=24/27|已动（无盾） | 模拟=23/27|已动,盾
修复后：hero_38·带道具·移动捡圣盾|MATCH|units+hero_38@(1, 3)=24/27|eatk=1|emove=2|已动 ; items-(1, 3)
```
根因（对齐 `heroes/hero_38_涌电技师.gd` 原文）：
- 电击敌人：`take_damage(maxi(1, effective_atk()), false, false, …, true)` → **`is_attack=true`**，
  可被圣盾格挡（消耗盾、免伤）、坚固可减；模拟原来用 `_sim_real_damage`（无视圣盾）→ 穿盾。
- 反噬自己：`take_damage(selfdmg, false, false, …)` → **不是** ignore_shield，圣盾照挡并消耗
  （非攻击伤害故坚固不减）；模拟原来也是 `_sim_real_damage` → 穿盾且盾还在。
- 修法：电击改 `_sim_take_damage(..., is_attack=true)`、反噬改 `_sim_hit_no_counter`（= `is_attack=false`）。

## 5. 用户实机那条"有效攻 预测3→实际1"= **真缺口，已修**（缓存标记过期窗口）

根因（代码路径坐实）：`Unit.ranged_adjacent` 是**缓存标记**，只在这些时机由 `Battle._sync_ranged_adjacent()`
刷新：出生 / 回合切边 / 移动落位 / 反击前 / **攻击收尾 `_finish_attack`** / 影丸随机步 / 变身。
**击退、换位、拉人、暗域占格、召唤落点都不刷新** → 存在"人已贴身、eatk 仍按未贴身算"的过期窗口，
该窗口内的攻击用旧攻击力（所以真实打出了 3 点），**收尾时才被修正成 1**；模拟原来按"实时相邻"读 → 报 3 ✗。

修法（fork）：`pin_flag` 改成真实的缓存语义（建局时由快照的 `ranged_adjacent` 定值，
harness 注入 = 与 `solid`/`atk_use_buff` 同一做法；没有该键时退回实时相邻的老口径），
新增 `_sim_refresh_pins()`（= 真实 `_sync_ranged_adjacent()` 全场重算）并只挂在真实的刷新点：移动落位后、反击结算前、攻击收尾后。

新场景 `被贴标记过期·出招`（`pin=false` 场景键复现过期态）：
```
SK|EV|hero_06·被贴标记过期·出招|MATCH|units[hero_06@(2, 4)]:16/16|eatk=3|emove=3|→14/16|eatk=1|emove=3|已攻 ; units[hero_13@(2, 3)]:40/40|eatk=2|emove=2|→37/40|eatk=2|emove=2|
```
即：**吃过期标记打出 3 点伤害、收尾后有效攻刷新成 1** —— 与 `RL/reports/ctr3.out.txt` #1 完全同形。
消融（把 `pin_flag` 换回实时相邻）后该场景立刻 DIFF：`真实 eatk=1 | 模拟 eatk=3` ✓ 证明场景守得住。
