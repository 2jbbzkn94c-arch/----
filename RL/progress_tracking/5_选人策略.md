# 5. 选人策略（部分实现 · 当前协议测不到）

> **本文档规矩**（用户 2026-09-20 定，见 `AGENTS.md`）：新内容**先整合进已有章节/表格**，不在文末另开章节；**已删的键统一记进「已删登记表」**，正文不留删除线行；**改引擎键/权重值/档位必须在同一次改动里同步本目录**；结尾保留版本锚点 + 计数行。

> 目标：**上场前选谁、什么时候换人**（对应你最早 5 条要求里的第 1 条「上场的英雄队伍强度高、自己队伍配合、同时能解对面的队伍」与第 4 条「替补上对人，判断要斩杀还是要填补队伍缺陷」）。
> 状态：**部分实现，但当前镜像协议测不到**。

## 这一层为什么独立

它**不在评分公式里**，属于另一个决策面：
- 方向 1~4 改的是"打的时候怎么评判局面 / 怎么选目标"；
- 本方向改的是"**开局部署选谁**"与"**阵亡后替补上谁**"，发生在战斗开始前 / 单位死亡时，与逐招搜索无关。

## 现状

**① 部署选人（开局）**：`src/Deploy.gd` 的敌方选人已从 `enemy_pool.pop_front()` 改成 **argmax（强度 + 配合 + 净克制 + 职能配比）**，被 `[替补]` 标记的英雄排除；
配套 `src/Battle.gd::_deploy_candidate_value()` 里加了 `_counter_deployed_score(cand)`（对我方已部署单位求净克制）。

**② 替补选人（阵亡后）**：`src/Battle.gd::_best_enemy_sub_idx()` 仍是**手写加权打分**（后勤 ±、`[替补]` +0.5、伤员 / 前线 …），**不看对面、不看战局需要** —— 待改。

**③ 难度分档：简单档 = 赛前选人"大幅拉平"（2026-09-21 用户拍板 · 已实现）**

用户原话：「**简单模式选人不在按评分机制，改为乱选**」，追问后定下两条口径：**范围 = 只改赛前两处**（选项 A）· **强度 = 保留一点点权重**（选项 B，照抄"强度的 10%"）。

| 项 | 内容 |
|---|---|
| 落点（只这两处） | ① **敌方卡组组建**：`src/Battle.gd::_synergy_pick_enemy()`（单机普通模式的敌方队伍，5~8 人）② **竞技场 2选1 的敌方选择**：`src/Battle.gd::_action_arena_enemy_pick()` |
| 改法 | 新增 `const SIMPLE_PICK_SCORE_W := 0.1` + `func _pick_weight(sc)`：**简单档（`GameState.ai_difficulty == 0`）** 权重 = `1 + 0.1 × max(评分, 0)`；**普通/困难/噩梦走原口径**（`max(评分,0) + 1`，逐位不变）。①处把抽取权重换成 `_pick_weight(sc)`；②处从"取最优（差<1.5 才随机）"改成**按拉平权重的掷签**（分值相近时≈五五开，拉开时也只是略偏）。 |
| 效果量（评分 sc 大致落在 10~30） | 简单档：最优/最差英雄的**相对权重 ≈ 3~4 倍**（原来是 **~30 倍**）⇒ 会真的拿出歪阵容，但不是纯均匀随机 |
| **故意不改的地方** | **开局部署选人**（`Deploy.gd::_enemy_candidate_value()`）与 **替补选人**（`Battle.gd::_best_enemy_sub_idx()`）—— 那两处被**真实/模拟两侧的"选人规则镜像"**共用，改了会破坏对拍；而且它们属于"战斗内决策"，不是"赛前选人" |
| 也**没**改 | `src/Menu.gd::_synergy_pick()`（**玩家自己**"随机组队"按钮的推荐权重）—— 那是给玩家的便利功能，不是 AI 的选人 |
| 怎么调"乱"的程度 | 只动 `SIMPLE_PICK_SCORE_W` 一个常数：**0 = 完全均匀随机**（等概率，只保证不重复）· 0.1 = 现役 · 1.0 及以上 ≈ 回到"几乎总挑最优" |
| 影响范围 | **只有简单档（难度 0）**；`GameState.ai_difficulty` 默认 1（普通）⇒ 工具/训练/对拍（`difficulty=2`、且 `-FixedDecks` 根本不会调这两处）**全都不受影响** |
| 怎么手动验 | 菜单选**简单**开局，连开几局看敌方队伍：应该**明显变歪**（会出现没坦克/双后勤/全脆皮这种），且不再总是同一批强英雄；切回普通/困难，敌方队伍应与以前一样 |

## 为什么现在测不到（两条硬约束）

| 约束 | 现象 |
|---|---|
| 所有跑批都用 `-FixedDecks`（阵容写死） | **部署那一步根本不发生** ⇒ 改了也测不出差别 |
| 镜像批次是 3 人阵容、没有替补席 | `measure.csv` 里 `subA` / `subB` **恒为 0** ⇒ 替补逻辑一次都没被触发 |
