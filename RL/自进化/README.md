## 纪律（不越界）

1. **引擎（`src/`）只保留"最小接线"**：档位 5 的权重文件路径、以及"难度 5 走我这份 AI 副本"的加载分支。
   我的**机制实现**放我自己的 `AI.gd`（由 `src` 同步而来），**不往 `src/BattleAI.gd` 里塞新东西**。
2. **不碰用户的档**：`噩梦.json` / `噩梦1.json` / 低三档**一字节不改**；删掉 `权重.json` ⇒ 难度 5 自动退回 `噩梦1` ⇒ 再退回 `噩梦`。
3. **跑批期间冻结引擎**（比 `RL/ai/AI_Battle.gd` 的 sha），对照一律用同引擎重跑。
4. **每个改动都记进 `账本.jsonl`**（原始数据）与 `reports/自进化_记录.md`（给人看的摘要）。
5. ⚠️ **我的 `.ps1` 必须带 UTF-8 BOM**（PS 5.1 读没 BOM 的中文注释会按 GBK 解 ⇒ 整份脚本语法报错、
   实测一次报 8 处）。**坑**：任何一次用编辑器/工具改 `RL/自进化/*.ps1` 都会把 BOM 抹掉
   ⇒ 改完必须补一遍（`[System.IO.File]::WriteAllText($p, $t, [System.Text.UTF8Encoding]::new($true))`），
   再用 `[System.Management.Automation.Language.Parser]::ParseFile()` 复验 0 错。同一个坑咬过两次（`Train.ps1` 一次、本文件夹两次）。
