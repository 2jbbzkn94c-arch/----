# AI 评分调试指南（你自己改哪里）

## 核心概念

敌方 AI 对每种走法算一个分数 `score`，选**分数最高**的那条走法。分数 = 各维度加总。想让 AI "变得更猛/更怂/更苟/更贪"，就是调这些**权重常数**。

## ① 攻击欲望（最影响"打不打"）

在 `_evaluate`（约 436 行）：

gdscript

复制

```
score += v if is_enemy else -v * 1.25   # ← 这个系数
```

- **调大**（如 1.5、1.8）→ AI 更看重"打玩家"的收益 → 更爱攻击、更激进；
- **调小**（如 1.0、0.9）→ AI 更想保自己单位 → 更保守。

## ② 威胁图（"怕不怕被反击"）

`_threat_map`（约 472 行）：

gdscript

复制

```
s -= ratio * 3.0   # ← 这个系数
```

- **调大**（如 5、8）→ AI 更怕走位暴露、更谨慎（但可能能打不打）；
- **调小**（如 2、1）→ AI 更敢顶着反击上（更猛，但可能送）。
- 还有 `_incoming_damage`：决定"某格下回合会被玩家打多少"，可选调低它的 `1.0` 阈值影响。

## ③ 集火

`_evaluate`（约 458 行）：

gdscript

复制

```
score += 5.0 * (u.hurt_times - 1)   # ← 集火权重
```

- 调大 → AI 更倾向把多个单位压在同一目标，专注击杀。

## ④ 胜负节奏（补刀 vs 苟）

`_evaluate`（约 450 行）：

gdscript

复制

```
score += float(player_dead) * 3.0      # 玩家快死时更想补刀
score -= float(enemy_dead) * 2.0       # 自己快输时更想保命
```

- 调大 `player_dead * 3.0` → 快赢时更激进；
- 调大 `enemy_dead * 2.0` → 快输时更怂/更保。

## ⑤ 走位定位（跑位倾向）

`_position_score`（约 508 行）：

- 坦克前压、后勤缩后、远程贴边缘、`保留移动力 +0.5`。
- 想减少"乱跑"：把"未移动 +0.5"删掉或调低；想更前压：调大坦克 y 权重。

## ⑥ 单位价值（谁值得打/保）

`_unit_value`（约 560 行）：`base = eatk*1.6 + hp*1.0`。

- 调大 `hp*1.0` → AI 更保高血单位 / 更想打高血价值敌人；调大 `eatk*1.6` → AI 更看重攻击力。

## ⑦ 难度（每步的"聪明"程度）

`_beam()`：`difficulty>=2 → 40`（搜索更充分=更强）。调大难度或 beam 数 → AI 更强。`_jitter()`：难度高抖动小（更接近纯最优）。

## 快捷调法

- **想更猛**：`-v*1.25`→`1.6`，`ratio*3.0`→`2.0`，集火 `5.0`→`6.0`。
- **想更稳**：`-v*1.25`→`1.0`，`ratio*3.0`→`5.0`。
- **想更抓机会杀**：`player_dead*3.0`→`5.0`。
