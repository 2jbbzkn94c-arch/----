酒馆纷争 单机版  ·  说明
================================================================

这是"本地假服务端"方案：原版 APK 一个字节都没改，
靠在本机跑一个小服务端，替掉早就关服了的官方服务器。

【你需要准备】
  1. Windows 电脑
  2. 雷电模拟器14（LDPlayer 14）—— 必须这个，别的不保证能跑
     https://www.ldplayer.net/
  3. 管理员权限（第一次运行要加两条防火墙规则）
     不需要装 Python，都打包好了

【怎么玩】
  1. 先打开雷电模拟器14，等它完全进入安卓桌面
  2. 双击本目录里的「启动.bat」，会弹 UAC 问你要管理员权限 —— 点是
  3. 等脚本自己跑完（会装游戏、配好一切、把游戏拉起来）
  4. 窗口不要关，玩的时候留着。Ctrl+C 可以结束

  第一次运行要几分钟（装一个 90MB 的包）。

【脚本会自动做的事】
  * 加防火墙规则（只需一次）
  * 把雷电的 ROOT 打开（配 iptables 要 root）
  * 在模拟器里把 *.nbdev.cc 的 DNS 查询劫持到本机
  * 起假服务端（登录、存档、开箱、天梯匹配都由它应答）
  * 装游戏、拉起来

【出问题了】
  双击「诊断.bat」，它会逐层告诉你哪里断了。
  把它的完整输出发回来即可。

【想改点东西】
  save.json  可以用记事本改（改完重启 启动.bat）：
    heros                        已解锁英雄（可玩段 8000000-8000042）
    rwcoin / rwgem / dust        金币 / 宝石 / 粉尘
    battle.enemy_is_real_player  false = 单机 AI 对手（默认）
    battle.last_result           0 = 胜  1 = 负

【已知情况】
  * 第一次进游戏会走教程，正常
  * 天梯对战是"秒配对手"，对手是 AI
  * 如果模拟器起不来：多半是 BIOS 里没开虚拟化（VT-x/AMD-V），
    或者被 Hyper-V / WSL2 占用了
